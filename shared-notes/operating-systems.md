# 操作系统基础

## 阅读顺序

进程/线程 → 用户态/内核态与系统调用 → 调度 → 地址空间与内存管理 → 同步和 IPC → 文件与设备抽象。

## 进程、线程与系统调用

进程是资源和地址空间的隔离/管理单位；线程是进程中的执行流，通常共享进程地址空间及打开资源，但拥有独立寄存器上下文和栈。进程/线程切换需要保存和恢复执行上下文，切换成本不只取决于调度函数本身，还包括缓存和地址空间影响。

系统调用是用户态请求内核服务的受控入口。调用会通过体系结构规定的指令/异常入口进入内核，内核校验参数并执行服务后返回。普通函数调用不等于系统调用。

## 调度与阻塞

调度器在可运行任务中选择执行对象。阻塞任务等待事件时不占用 CPU；忙等持续占 CPU。实时系统关注优先级、最坏响应时间、抢占和优先级反转；Linux 通用调度器与硬实时 RTOS 的目标和接口不能简单等同。

## 虚拟内存

虚拟地址空间提供隔离和映射抽象。页表描述虚拟页到物理页的映射；缺页异常可能用于分配页或处理非法访问。内核态与用户态访问权限由架构/MMU 等机制共同执行。

## 同步与死锁

竞态是结果依赖未同步的并发执行顺序。临界区是访问共享状态的代码范围。锁应保护不变量，而非只保护某个变量；锁的选择还取决于是否可睡眠、是否在中断上下文、持有时间和竞争情况。

死锁常用必要条件：互斥、持有并等待、不可抢占、循环等待。实际避免方法包括固定加锁顺序、缩短持锁范围、避免锁内调用未知回调和避免错误的嵌套。

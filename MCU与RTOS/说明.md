# MCU + RTOS

## 学习状态

中断和总线基础已学习，后续结合具体 MCU 外设和 RTOS 实践继续深化。本仓库中的通用基础复习入口见[通用基础知识](../通用基础/说明.md)。

## 阶段建议

1. **C 与硬件基础**：指针、结构体、位操作、volatile 的适用场景、内存映射、中断。
2. **裸机外设**：GPIO、UART、定时器、PWM、SPI、I2C、ADC、DMA；理解轮询、中断和 DMA 的取舍。
3. **MCU 工程**：启动文件、向量表、链接脚本、时钟树、烧录和调试。
4. **RTOS 核心**：任务状态与调度、优先级、时间片、队列、信号量、互斥锁、事件组、软件定时器。
5. **实时系统设计**：中断服务程序约束、任务划分、响应时间、优先级反转、栈水位、死锁与竞态。
6. **应用实践**：分层驱动、状态机、协议解析、看门狗、低功耗和故障恢复。

建议先用裸机完成 UART 和定时器实验，再引入 RTOS；这样更容易区分芯片机制与操作系统机制。可先选择一种 MCU 和一种 RTOS 深入实践，例如 Cortex-M + FreeRTOS，之后再比较其他方案。

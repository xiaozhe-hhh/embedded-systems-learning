# 每日学习日志

每天复制 [`_template.md`](_template.md) 为 `YYYY-MM-DD.md`，只记录实际发生的学习。每篇标明学习主线（Linux、基础复习、代码随想录、RTOS 或项目）及实际时长。计划内容不自动算作完成；科研繁忙时可记录“部分完成/顺延”。

## 记录原则

- 总结用自己的话，避免只粘贴教材或源码。
- 源码学习写清版本、路径、符号和读到的调用关系。
- 保留不确定点和错题，方便之后复习。
- 一天没有学习也可以不创建日志，不补写虚假的记录。
